
# Market Basket Analysis on Bakery Sales Data: An Apriori and FP-Growth Approach

## 📝 Overview

This repository contains a comprehensive data analysis project focused on performing **Market Basket Analysis (MBA)** on sales transaction data from **The Bread Basket Bakery** in Edinburgh.

The project employs two fundamental data mining techniques—**Apriori** and **FP-Growth**—to identify frequent itemsets and generate actionable association rules. The goal is to transform raw sales data into strategic business intelligence for retail optimization.

## 📌 Domain and Dataset

* **Domain:** The Bread Basket Bakery (Edinburgh)
* **Dataset Size:** The analysis is conducted on over **20,500 entries** spanning more than **9,000 unique customer transactions**.
* **Data Columns:** `Transaction` ID, `Item`, `date_time`, `period_day`, and `weekday_weekend`.

## 🧠 Methodology and Algorithms

The core of this analysis involves implementing and comparing two robust algorithms for association rule mining:

### 1. Apriori Algorithm
A classic algorithm used for finding frequent itemsets. The notebook uses the Apriori function from the `mlxtend` library to generate rules based on a defined **support threshold (1%)**.

### 2. FP-Growth (Frequent Pattern Growth) Algorithm
Used as a modern, efficient alternative to Apriori. FP-Growth is often faster and more memory-efficient as it utilizes a tree structure to encode the dataset, which is advantageous for larger transaction datasets.

## 📈 Key Stages of the Project

1.  **Data Pre-processing:**
    * Conversion of the `date_time` column to the proper datetime object.
    * Feature engineering to extract granular time data, including `time`, `hour`, `month`, and `weekday` names for dynamic analysis.
    * Transaction encoding to convert the list-based data into a one-hot encoded matrix suitable for association rule algorithms.
2.  **Exploratory Data Analysis (EDA):** Visual analysis of purchasing dynamics over time (daily, monthly) and identification of the top 20 most popular items, which include **Coffee (26.68%)**, **Bread (16.21%)**, and **Tea (7.00%)**.
3.  **Association Rule Mining:** Generation of frequent itemsets and association rules using both Apriori and FP-Growth, setting a minimum support of 1% and a minimum confidence threshold to discover meaningful purchase patterns.

## 💡 Business Impact

The insights derived from the association rules generated by this project are directly applicable to the bakery's business strategy, enabling decisions on:

* **Optimizing Product Placement:** Strategically placing items that are frequently bought together (e.g., placing jam next to bread).
* **Cross-Selling:** Creating effective product bundles and combo offers.
* **Targeted Promotions:** Designing marketing campaigns based on customer behavior.
* **Inventory Management:** Anticipating demand for linked products to prevent stockouts and reduce waste.
